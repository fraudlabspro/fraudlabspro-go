# FraudLabs Pro Go SDK

This Go module enables user to easily implement fraud detection feature into their solution using the API from [FraudLabs Pro](https://www.fraudlabspro.com).


Below are the features of this Go module:

* Fraud analysis and scoring
* Credit card issuing bank validation
* SMS verification and validation

This module requires API key to function. You can [sign up for a free API key at FraudLabs Pro](https://www.fraudlabspro.com/checkout-micro).

# Developer Documentation
